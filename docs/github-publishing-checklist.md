# GitHub Publishing Checklist

Use this checklist before publishing a copy of this example.

1. Confirm `.env` is ignored and is not staged.
2. Search the repository for real keys, tokens, customer names, emails, phone numbers, prompts, responses, and trace links.
3. Keep only fictional local tool data.
4. Run the local unit tests:

   ```powershell
   .\scripts\run-tests.ps1
   ```

5. Read the root README from a new developer's point of view. The basic run command must be easy to find.
6. Commit only the clean example repository files.
