## 3. How to Verify a Trace Locally

To verify any trace without manual inspection in the browser:

```powershell
# Run trace validation by ID
.\scripts\check-trace.ps1 -TraceId <YOUR_TRACE_ID>
```
The script confirms that:
- Root workflow and child spans are connected.
- Canonical model generations contain token usage and cost.
- Privacy policies are respected (no message content leakage).
